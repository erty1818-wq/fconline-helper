# 포지션 OVR 공식과 인게임 OVR 계산

스쿼드 메이커 카드에 뜨는 숫자는 **인게임 OVR**이다. 강화, 적응도, 팀컬러(전체·세부 스탯), 집중훈련을 모두 더한 값이다. 이 문서는 그 계산 방법과 근거를 정리한다. 코드: `src/FcHelper.Market/OvrFormula.cs`

## 1. 포지션 OVR 공식 [계산]

```
OVR(포지션) = ⌊ Σ (스탯 × 가중치) ÷ 100 ⌋      가중치는 정수, 포지션마다 합 100
```

### 가중치를 구한 방법

1. **샘플 수집.** 공식 데이터센터 `POST /datacenter/PlayerAbility`(선수 상세 페이지가 쓰는 요청)로 카드를 받았다.
   - 244장, 로컬 시세 DB의 포지션 그룹 10개에서 OVR 구간별로 고르게 뽑았다. 2초에 1번, 개인 사용 범위다.
   - 받은 값은 +1 기준 스탯 34개와 16개 포지션 OVR이다.
2. **포지션별 스탯 범위.** 스탯마다 데이터센터가 `data-positon` 속성으로 관련 포지션을 표시한다. 그 포지션에 표시된 스탯만 변수로 두었다.
3. **정수 가중치 탐색.** 가중치 합을 100으로 고정했다. 모든 카드에서 `100×OVR ≤ Σ가중치×스탯 ≤ 100×OVR+99`가 성립하는 정수해를 찾았다.
   - 방법은 최소제곱으로 시작점을 잡고, 가중치를 1씩 옮기는 국소 탐색을 여러 번 새로 시작한 것이다.
   - **결과: 16개 포지션 모두 244장 전부와 일치했다.**
4. **답이 하나인지 확인.** 좌우 포지션(LB/RB, LWB/RWB, LM/RM, LW/RW)을 따로 맞췄는데 같은 가중치가 나왔다. ST는 오래 알려진 FIFA 공식과 같다.
5. **보류 검증.** 맞춤에 쓰지 않은 카드 40장을 다시 받아 대조했다.
   - 각 카드를 기본 상태 한 번, 데이터센터에서 강화 +5~+11·적응도 5·소속/특성 팀컬러를 걸어 한 번 받았다.
   - 16개 포지션 기준 **1,280건 모두 일치했다.**

## 2. 인게임 OVR = 기본 + 단계별 보너스

| 단계 | 더해지는 것 | 근거 |
|---|---|---|
| +1 기준 | 데이터센터 목록의 포지션 OVR (적응도 +1 포함) | 데이터센터 |
| 강화 | 모든 스탯 +(단계 보너스 − 3). 예: +8은 +15 | 데이터센터에서 +8 선택 시 모든 스탯 +15 확인 |
| 적응도 | 모든 스탯 +(적응도 − 1). 최대 5면 +4 | 데이터센터 적응도 5: 모든 스탯 +4 확인 |
| 팀컬러 전체 능력치 | 모든 스탯 +N | 데이터센터 팀컬러 상세 |
| 팀컬러 세부 스탯 | 해당 스탯만 +N. 가중치가 있는 포지션만 오른다 | 예: 잉글랜드 3단계는 골 결정력·긴 패스가 더 올라 CAM·CM만 +4, 나머지 +3 |
| 집중훈련 | 고른 스탯 +1~+2 | 아래 3 |

- 모든 스탯에 같이 더해지는 보너스는 가중치 합이 100이라 OVR에 그대로 더해진다.
- 세부 스탯 보너스는 소수점 아래가 쌓여서 올림 없이 내림으로 반영된다. 그래서 카드 스탯 34개를 알아야 정확히 계산할 수 있다.
  - 앱은 카드를 처음 넣을 때 그 카드의 스탯을 한 번 받아 일주일 보관한다(요청 1번).
  - 받기 전에는 내림 추정값을 `~` 표시와 함께 보여 준다.
- 팀컬러를 겹치는 규칙:
  - 소속 팀컬러는 선발 전원에게 적용된다.
  - 특성(관계) 팀컬러는 그 팀컬러에 속한 선수에게만 적용된다.
  - 강화 팀컬러는 도달한 것 중 가장 높은 하나만 적용된다.

## 3. 집중훈련 [외부 설명 기준]

- 강화 +10까지는 스탯 5개, +11부터는 6개를 고를 수 있다. 스탯마다 +1 또는 +2다.
  - 출처: 커뮤니티 계산기 설명(fc-info, 인벤 등). 공식 데이터센터에는 규칙이 없다.
- 앱의 추천:
  1. 그 포지션에서 가중치가 가장 큰 스탯 5개(또는 6개)를 +2씩 올리는 안을 보여 준다.
  2. 카드 스탯을 알면 다음 OVR까지 남은 점수를 계산한다.
  3. "+1만 원하면" 최소로 어느 스탯을 올리면 되는지도 알려 준다.
- 인게임 훈련 결과는 실제로 무엇이 붙었는지에 따라 달라진다. **집중훈련 최대 반영** 스위치는 최대치(+2씩)를 가정한 값이다.

## 4. 미니페이스온

- 공식 스쿼드메이커의 "선수 사진 변경" 목록 `POST /squadmaker/GetPlayerCustomImgList`을 쓴다. 한 선수의 모든 시즌 사진이 들어 있고, 공식 CDN 이미지를 한 번 받아 `%LOCALAPPDATA%\FcHelper\faces`에 보관한다.
- 카드마다 따로 고를 수 있다: 이 시즌 기본 사진, 다른 시즌 사진, 내 이미지 파일, 사진 없음.
- 라이선스 문제로 내려간 사진(403)은 목록에서 뺀다.
