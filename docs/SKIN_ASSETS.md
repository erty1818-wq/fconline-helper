# 스킨 이미지 교체 가이드 (이미지 생성 AI용)

FC Online Helper의 화면 이미지는 **정해진 이름의 PNG 파일**로 바꿀 수 있다. 다시 빌드할 필요가 없다.

- 넣는 곳: `%LOCALAPPDATA%\FcHelper\skin\` (탐색기 주소창에 그대로 붙여넣기) — 또는 exe 옆 `skin` 폴더
- 파일 이름 = 아래 표의 키 + `.png` (예: `pitch.png`)
- 파일이 없거나 깨져 있으면 기본 그림(코드로 그린 벡터)이 나온다. 바꾼 뒤 앱을 다시 켜면 적용된다.

## 글꼴 바꾸기

`%LOCALAPPDATA%\FcHelper\skinonts\` 폴더에 `.ttf`·`.otf` 파일을 넣으면 앱 전체 글꼴이 그 폰트가 된다(예: Pretendard, SUIT — 둘 다 무료 OFL). 폴더가 비어 있으면 설치된 Pretendard → SUIT → Noto Sans KR → 맑은 고딕 순으로 쓴다.

## 공통 스타일 (모든 이미지에 적용)

앱은 어두운 테마다. 이미지가 튀지 않게 다음을 지킨다.

- 배경색 `#15181D`, 패널 `#1E2229`, 선 `#2C323B`, 글자 `#E8EAED`, 보조 글자 `#9AA3AE`
- 강조색은 민트 그린 `#3DDC97` 한 가지만, 보조 강조 `#6CB6FF`(정보)·`#FFB547`(주의)는 아주 적게
- 톤: 차분하고 고급스러운 스포츠 분석 도구. 네온·과한 광택·실제 선수 얼굴·실제 구단 로고·FC온라인/EA/넥슨 로고 사용 금지 (저작권·상표)
- 글자를 이미지에 넣지 않는다 (앱이 한국어로 따로 표시한다)
- 투명 배경이 필요한 것은 PNG 알파 채널 사용

**가볍게:** 파일은 PNG 한 장당 200KB 이하(배경만 400KB 이하), 전체 2MB 이하. 앱은 켤 때 한 번 읽고 캐시한다. 큰 사진·애니메이션은 쓰지 않는다.
글자·숫자는 이미지에 넣지 않는다: 이름·OVR·가격은 앱이 그 위에 그린다.

아이콘 공통: 선 두께 3px 정도의 라인 아이콘, 색 `#E8EAED` 한 가지(선택 상태는 앱이 배경으로 표시), 가장자리 4px 여백. 한 파일이라도 넣으면 그 메뉴는 기본 글리프 대신 이미지를 쓴다.

## 이미지 AI에게 줄 한 줄 요약
