# MV-11 · 소속 11명과 실사용 역할을 먼저 맞추는 AI 스쿼드

2026-10-26, Codex. 금액은 억 단위다. 인게임 OVR은 목적 포지션의 능력치·강화·적응도·팀컬러를 합산한 예상 표시값 **[추정]**이다. 실제 게임에서 직접 확인한 OVR이 아니다.

## 최신 랭커 표본

- 공식경기 상위 100명을 공식 데이터센터에서 다시 찾고, NEXON Open API로 각자의 최근 공식경기 선발을 받았다. **2026-10-26 16:09 KST, 선발 11명을 확인한 98팀**을 실제 앱 DB의 `ranker.squads`에 저장했다. 앞선 작업 복사본의 2026-09-25·99팀을 최종 비교 근거로 사용하지 않는다.
- 시세는 완료 스냅샷 #11(2026-10-25 23:36 KST), 데일리 차트는 2026-10-25 자료다. 랭커 가격·급여 분배에 쓸 수 있는 팀은 96팀이었다.
- 100억의 절반~두 배, 즉 **50~200억**으로 현재 시세 환산이 가능한 완전한 선발은 34팀이었다. 이 표본에서 소속 선수 11명을 모두 만족하는 빈도를 센다.

| 소속 | 34팀 중 해당 소속 11명을 만족하는 팀 |
|---|---:|

이는 상위 100명의 최근 스쿼드 중 가격을 확인한 작은 표본이다. 전체 FC 이용자의 예산별 점유율로 일반화하지 않는다. 한 선발이 여러 소속 조건을 만족할 수 있으므로 표의 합은 34일 필요가 없다. 예산대 표본이 3팀 미만이거나 소속 빈도를 확인하지 못하면 전체 데일리 차트 인기 소속을 쓰며 `[추정]`을 표시한다. 날짜가 지난 캐시로 대체한 경우 표본 날짜와 갱신 실패도 표시한다.

## 바뀐 추천 순서

1. 소속을 직접 고르지 않았으면 예산대에서 많이 쓰인 소속을 우선한다. 고정 선수와 소속이 맞고 11명 후보가 있는 소속만 남긴다.
2. 완성 가능한 인기 소속 최대 4개를 비교한다. **모든 추천은 같은 소속 11명**, 급여·예산 이내, 축구선수 중복 없음이 필수다. 고정 선수도 소속 밖이면 명확한 안내와 함께 거절한다. 혼합 소속 추천으로 대체하지 않는다.
3. 카드의 시장 프리미엄은 참고 정보로 유지한다. 추천의 강함은 팀 전체의 인게임 예상 OVR로 비교한다. 최강 대비 평균 OVR 0.5 이내에서 저렴한 안은 균형, 1.0 이내에서 저렴한 안은 가성비, 1.5 이내에서 랭커 사용이 많은 안은 랭커픽으로 정한다. 앱은 가성비 안을 처음 선택한다.
4. 편집·강화 변경·되돌리기·보관함에서도 자동으로 고른 소속을 유지한다. 새 AI 요청에서 자동 선택은 예산을 기준으로 다시 비교한다.

카드 후보 70개와 빔 2,000개를 쓰는 제한된 조합 탐색이다. 모든 가능한 팀·시즌·강화 조합의 수학적 최적해를 보장하지 않는다.

## 포메이션과 포지션

- **4-2-2-2의 LAM/RAM:** 윙어·측면 미드 주포지션 선수와 그 자리에 실제로 쓰인 랭커 카드를 우선 후보로 삼는다.
- **4-2-2-1-1의 CF:** CAM 선수도 정상 후보로 삼는다. CF 주포지션·랭커 실제 사용 카드도 조건에 따라 들어갈 수 있다.
- 미기재 포지션의 OVR은 가중치에 필요한 능력치를 모두 수집한 경우에만 계산한다. RW의 OVR을 CAM/CF OVR로 복사하지 않는다. 확인하지 못한 값은 `[추정]`이다.
- 포메이션 변경 시 기존 위치, 새 역할, 공식 기재 위치, 전체 능력치 계산 순서로 재배치한다. 4-2-2-2 → 4-2-2-1-1 변경에서 선수가 사라지는 경우를 테스트했다. 골키퍼와 필드 선수는 서로 바꾸지 않는다.
