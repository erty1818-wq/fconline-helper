# MV-14: 수요 자료와 모델 섞기로 시세 오차 줄이기

사용자 요청: "오차 범위를 어떻게든 더 줄여야해". 모든 숫자는 스냅샷 13(2026-10-30), +11, 시장 연관성 [추정]이다.
시험 방법은 MV-12와 같다. 처음 보는 카드(5묶음)로 재고, 선수 절반으로 고른 뒤 나머지 절반으로 확인한다.

## 넣은 것

1. **공식 경기 사용량** (`CardUsage`): 저장된 2,739경기에서 카드별 선발 횟수. 카드 사용 2배에 약 +9.4% [추정]. 단독으로는 선택 −0.008, 확인 −0.011(구간이 0에 걸침)이다. 경기 기록이 적은 PC에서는 효과가 더 작을 수 있다.
2. **작은 나무 모델 30%** (`PriceTrees`, `TreeWeight`): 단독으로는 선형보다 나쁘지만(33%) 틀리는 방향이 달라 섞으면 줄어든다. 사용량과 합쳐 로그 오차가 선택 −0.019(−0.031~−0.008), 확인 −0.024(−0.035~−0.013)이다. 200회, 잎 15, 64열 정도라 시장 전체 적합과 검증이 CLI에서 약 10초 걸린다.
3. **자기 시세를 안 본 나무**: 화면의 예상가는 그 카드를 뺀 묶음의 나무를 쓴다. 나무 하나를 전체 카드로 학습하면 카드마다 자기 시세를 외워 "예상가와 비슷함"으로 보이게 된다.
4. **카드별 예상 범위와 믿음도** (`BandOf`, 가성비 표, 선수 정보 창): 시세를 보기 전에 아는 것(다른 카드 수, 사용량, 시즌의 평소 오차, 선형과 나무의 차이 등)으로 어려운 카드를 가린다. 스트라이커 화면의 네 구간 오차는 19%, 34%, 38%, 45%다. 선수 절반 확인에서도 23%, 33%, 40%, 41%로 갈렸다. "모델 오차 범위 내" 판정도 포지션 전체가 아니라 이 구간의 오차로 한다.

## 넣지 않은 것 (재현되지 않음)

Huber 손실, 학습 범위 넓히기(110·105·100+), 학습 목표에 +10 섞기(오히려 나쁨), 최근 3회 평균 목표, 형제 카드 거리 2·5·8, 특성·포지션이 다른 형제 덜 믿기, 포지션별 모델 섞기(나무에 더 보태는 효과 없음), 평점·공격포인트·승률, 팀컬러 안 희소성, 특성 카드에 나무 더 주기, 특성 카드 치우침 보정(나빠짐), 나무에 강화 후 능력치·궁합 열 추가. 시즌 잔차(−0.002)와 유연한 OVR 곡선은 효과가 작아 코드를 늘리지 않았다.

거래 활발도(며칠이나 시세가 바뀌었나)는 선택 −0.003, 확인 −0.013으로 확인 쪽에서만 뚜렷했다. 저장된 날이 11일뿐이고 +11은 관측이 대부분 하루라서 지금은 넣지 않았다. 일별 시세가 쌓이면 `tools/market/mv14_activity.py`로 다시 잰다.

## 어디까지 줄일 수 있나

- 잔차(하한 제외) 표준편차 0.582. 나흘 뒤 같은 카드의 잔차와 상관 0.88, 한 달 뒤 0.74. 사라지는 몫만 남으면 오차 15%(나흘), 23%(한 달)다. **즉 시세 잡음만으로 15~23%는 누구도 못 맞히고, 나머지는 스펙에 없는 카드 고유 수요다.**
- 그 카드의 +10 시세까지 알아도 최상위·하한 제외 오차는 약 24~25%다. +10과 +11 잔차 상관이 0.49뿐이라 +11 값은 +11만의 사정이 크다.
- 스냅샷 11, 12의 시세를 그대로 쓰면 10.5%다. 시세를 베끼는 것이라 가치 판단에는 못 쓴다.
- 다른 카드가 전혀 없는 선수를 스펙만으로 맞히면 35.5%다.
- 인기 특성 최상위 카드는 치우침이 +3%로 거의 없고 오차는 31%다. 다른 카드가 있으면 30%, 없으면 61%이고, 26TOTS 46%, UC 43%, PTG 50%처럼 특정 시즌에 몰린다. 평균을 옮겨서는 줄지 않는 카드별 수요다.
