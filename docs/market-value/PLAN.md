# 선수 값어치 모델 고도화 계획

## 목표

최신 이적시장 가격을 이용해 선수 카드의 구성 요소별 값어치를 포지션·강화 단계별로 분리하고, 그 결과를 가성비 찾기와 스쿼드 짜기의 환산 OVR에 반영한다. 모든 수치는 시장 가격에서 추정한 연관성이며 인과관계가 아니므로 화면에는 `[추정: 시장 회귀]`로 표시한다.

## 값어치 요인

- OVR과 강화 단계, 급여, 시즌
- 약발 4와 양발(약발 5)
- 키, 체중, 체형
- 소속 팀컬러와 특성 팀컬러
- 신규 특성, 개인기
- 포지션별 모든 세부 능력치

## 작업 순서

1. Codex 1차: 공식 리밸런싱 내용과 현재 모델을 대조하고, 최신 시세 표본으로 값어치 모델·기준표를 만든다.
2. Claude Code 독립 검수: 통계 설계, 게임 규칙, 누락 데이터, 가성비·스쿼드 반영 경로를 검토한다.
3. Codex 최종 검수: Claude 지적을 재현하고 필요한 수정을 반영한 뒤 빌드·테스트·시장 표본 검증을 다시 수행한다.

## 설계 원칙

- 공식 데이터센터와 NEXON Open API만 사용한다.
- 최신 완료 시세 스냅샷만 학습해 패치 전후 가격을 섞지 않는다.
- 포지션 그룹별로 `ln(가격)`을 학습하고 OVR·시즌을 통제한 뒤 각 요인의 가격 차이를 계산한다.
- 특성·팀컬러·신체 구간은 해당 선수와 비교 선수 각각 8명 미만이면 제외하고, 그 이상도 릿지 정규화한다. 같은 선수의 시즌 카드를 군집으로 묶어 근사 구간을 계산하고, 해당 선수 10명 미만은 판정하지 않는다.
- 소속 팀컬러와 특성 팀컬러는 분리한다. 강화 팀컬러는 카드 가격 요인이 아니라 강화 단계에서 결정되는 보너스로 계산한다.
- 가성비 찾기는 예측 시세와 검증 오차를 함께 표시한다. 스쿼드 환산 OVR에서 팀컬러 소속 가격 프리미엄은 제외하고 실제 팀컬러 보너스를 적용한다.
- 패치 직전 스냅샷과 일별 시세를 고정 보관한다. 패치 전후 동일 카드의 로그 가격 차이에서 포지션·시즌·OVR 구간별 공통 추세를 제거하고 네 특성을 함께 추정한다. 이는 전후 연관성이며 단일 사전 관측으로 인과 효과를 확정하지 않는다.
