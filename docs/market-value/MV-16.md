# MV-16: 사용자가 설명한 시세 이유 시험

사용자 설명: 스켈리·엔소·25UCL 키미히는 그 낮은 급여에 그 성능을 내는 카드가 없어서 비싸다(특히 CDM·풀백, 아스날 같은 팀 안에서). 26TOTS 뎀벨레는 체감이 좋고, 대장 카드이고, 슛이 좋고, 파리 공격수 중 최고다. 리자라쥐는 매물이 많이 풀린 것 같다.
모든 숫자는 스냅샷 13(2026-10-30), +11, 시장 연관성 [추정]이다. 기준은 MV-15 앱 모델이고, 선수 절반으로 고른 뒤 나머지 절반으로 확인한다. 나무 씨앗은 3개다.

**결론: 설명의 방향은 대부분 자료와 맞지만, 오차를 줄이는 열은 찾지 못했다. 앱 모델은 MV-15 그대로다.**

## 자료와 맞는 것

**급여 값은 포지션별로 크게 다르다.** 같은 OVR·능력치에서 (전체 자료 적합):

| 포지션 | 급여 1 낮으면 | OVR 1 높으면 |
|---|---|---|
| FB | +41% | +34% |
| CB | +31% | +39% |
| CDM | +25% | +31% |
| CM | +18% | +36% |
| SM | +16% | +46% |
| CF | +3% | +43% |
| ST | +3% | +45% |
| CAM | +1% | +38% |
| W | +1% | +34% |

사용자는 CDM·풀백을 말했고, 자료에서는 센터백도 크다. 같은 선수의 OVR 차이 1 이하, 급여가 다른 카드끼리 비교해도 CDM·FB는 급여 1 낮은 쪽이 중앙 +27%(53쌍, 사분위 −29~+100%)이고 나머지는 −25%(255쌍)다. 이 값은 이미 `pay×포지션` 열로 모델에 있다.

**대안이 없는 카드는 CDM·풀백에서 예상보다 비싸다.** 대안은 같은 포지션에서 급여가 같거나 낮고 OVR이 같거나 높은 카드 수다.

| 구간 (하한 제외) | 카드 | 시세 / 예상, 중앙 |
|---|---|---|
| CDM·FB, 대안 3 이하, 10경기 이상 | 27 | +24% |
| 그 외, 대안 3 이하, 10경기 이상 | 61 | +4% |
| CDM·FB, 대안 3 이하, 10경기 미만 | 20 | +7% |
| 그 외, 대안 3 이하, 10경기 미만 | 37 | −6% |

**키미히 예측이 맞았다.** 사용자가 수치를 보기 전에 25UCL 키미히가 예상보다 비쌀 것이라고 했고, 시세 73.4억에 예상 34.1억이다. 대안은 230장 중 0장이다. 스켈리는 299장 중 0장(같은 값 1장 포함 시 1장), 엔소는 297장 중 2~3장이고, 싼 CH 리자라쥐는 27~64장이다(앞은 포지션별, 뒤는 포지션 묶음 기준).

## 자료와 다르거나 잴 수 없는 것

**뎀벨레.** 26TOTY가 OVR과 슛 능력치 모두 26TOTS보다 높고 값은 4분의 1이다. 대장 카드나 슛으로는 이 값 차이가 설명되지 않는다. 급여 2, 사용량, 특성 차이는 있지만 이 한 쌍으로 원인을 가릴 수는 없다. 체감은 공식 자료에 없고, 대리 지표인 평점은 오차를 줄이지 못했다.

| 카드 | OVR | 급여 | 골 결정력 | 슛 파워 | 특성 | 경기 (+11) | 시세 (스냅샷 순) |
|---|---|---|---|---|---|---|---|
| 26TOTS | 123 | 31 | 126 | 128 | 트릭스터 | 122 (3) | 289→560→535→630억 |
| 26TOTY | 125 | 33 | 129 | 130 | 스피드스터 | 13 (0) | 82→158→158→158억 |

**리자라쥐.** 매물 수는 공개 자료에 없어서 재지 못했다. 저장한 것은 시세와 변동 횟수뿐이다.

## 시험한 열 (MV-15 기준, 평균 로그 오차 차이)

| 열 | 전체 선택 | 전체 확인 | 비고 |
|---|---|---|---|
| 급여 대안 수·절약·OVR 차이 | −0.000 | +0.002 | 대안 3 이하 카드 확인 +0.021로 나빠짐 |
| 위 + 수비 포지션 따로 | +0.000 | +0.003 | |
| 팀 안 급여 대안 | −0.003 | +0.002 | 120+ 특성 있음 확인 +0.012로 나빠짐 |
| 대장 카드 | −0.004 | −0.004 | 구간이 0에 닿음, 경기 300장 확인 +0.006 |
| 팀 공수 안 최고 | −0.000 | +0.002 | |
| 평점 | −0.001 | −0.002 | |
| 대안 없음 × 쓰임 | +0.001 | +0.002 | |
| 급여 곡선 | +0.001 | +0.003 | |
| 급여 × OVR·쓰임 | −0.003 | −0.003 | 파이썬에서 경기 300장 −0.016, −0.021 |

마지막 줄만 앱 코드에 넣어 짝 비교했다. +11에서 전체 −0.001, −0.001(구간이 0에 걸침), 실사용 +0.003, +0.001, 120+ 특성 있음 +0.009, +0.002, 경기 300장 −0.007, −0.020이다. 포지션별 중앙값도 CDM 23.7→32.9%, W 28.7→33.4%로 나빠져서 되돌렸다.

왜 안 주는가 (해석, 확인되지 않음): 급여 값은 이미 포지션별로 모델에 있고, 대안이 없는 카드끼리도 편차가 커서(오차 36%) 평균을 올려도 많이 줄지 않는다. 카드 수도 88장뿐이다. 스켈리 예상은 12.2억에서 18.7억까지만 오르고, 쿠쿠레야 PTG는 일부 조합에서 오히려 멀어졌다.

재현: `tools/market/mv16.py`(대안, 팀, 대장, 평점), `tools/market/mv16_pay.py`(급여 값, 뎀벨레, 쓰임과 교차).
