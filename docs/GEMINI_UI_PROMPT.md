# 제미나이(이미지 생성 AI)용 UI 고급화 프롬프트

아래 블록을 통째로 붙여 넣고, 그다음 "이미지 1번부터 만들어 줘"처럼 한 장씩 요청한다.
만든 PNG는 `%LOCALAPPDATA%\FcHelper\skin\` 에 **파일 이름 그대로** 넣고 앱을 다시 켜면 적용된다(빌드 불필요).
없는 파일은 지금 모양(코드로 그린 것)이 그대로 나온다. 자세한 표는 `docs/SKIN_ASSETS.md`.

---

```
너는 게임 보조 앱의 UI 아티스트다. Windows 데스크톱 앱 "FC Online Helper"(축구 게임 FC온라인의 전력 분석·스쿼드 메이커)의 화면 이미지 에셋을 만든다.

[앱 분위기]
- 다크 테마의 고급 스포츠 분석 도구. 참고 톤: 프리미엄 축구 데이터 대시보드, 경기장 야간 조명, 유리 질감(글래스모피즘)을 아주 절제해서.
- 색: 배경 #15181D, 패널 #1E2229, 한 단계 밝은 패널 #252A33, 선 #2C323B, 글자 #E8EAED, 보조 글자 #9AA3AE.
- 강조색은 민트 그린 #3DDC97 하나. 보조색 파랑 #6CB6FF, 주황 #FFB547은 아주 조금만.
- 네온, 과한 광택, 무지개 그라데이션, 3D 렌더 느낌은 쓰지 않는다.

[꼭 지킬 것]
- 이미지에 글자·숫자·로고를 넣지 않는다. 이름·OVR·가격·메뉴 글자는 앱이 이미지 위에 한국어로 그린다.
- 실제 선수 얼굴, 실제 구단 엠블럼, FC온라인·EA·넥슨 로고는 절대 그리지 않는다(저작권·상표).
- 파일은 PNG. 투명이라고 적힌 것은 알파 채널로 배경을 비운다.
- 가볍게: 한 장 200KB 이하(배경만 400KB 이하). 크기(px)는 정확히 지킨다.
- 가운데에 글자가 올라가는 이미지(카드 틀, 패널 배경)는 가운데를 비우고 가장자리에만 장식한다.

[만들 이미지] 파일 이름 · 크기 · 배경 · 설명
1. background.png · 1920×1080 · 불투명 · 모든 창의 배경. #15181D 바탕에 아주 옅은 경기장 야간 조명 빛(오른쪽 위에서)과 잔디 결. 대비가 낮아 위의 글자가 잘 읽혀야 함.
2. pitch.png · 600×800 세로 · 불투명 · 위에서 내려다본 축구장, 위쪽이 공격 방향. 어두운 녹회색 잔디(#17231D 근처), 흰 선 40% 불투명도로 얇게, 은은한 잔디 줄무늬, 가장자리 비네팅. 선 위치: 바깥선 여백 20px, 하프라인 y=400, 센터서클 반지름 70, 페널티박스 폭 300·깊이 120. 선수 카드 11장이 위에 올라가므로 복잡하면 안 됨.
3. card-frame.png · 272×220 · 투명 가능 · 피치 위 선수 카드의 틀. 어두운 유리 카드(#252A33), 위쪽 가장자리에 얇은 하이라이트, 아래쪽 은은한 민트 빛, 모서리 반경 20px. 가운데는 비움.
4. card-empty.png · 272×220 · 투명 · 빈 자리 카드. 반투명 어두운 카드에 점선 테두리(#2C323B), 가운데 비움.
5. home-card.png · 560×360 · 불투명 · 홈 화면 메뉴 카드 배경. #1E2229 패널, 아래쪽에서 민트 빛이 은은하게 번짐, 가장자리 1px 밝은 테두리 느낌. 왼쪽 위에 아이콘·제목이 올라감.
6. logo.png · 64×64 · 투명 · 원형 앰블럼. 민트 그린 바탕에 추상적인 공·방패 모티프. 글자 없음.
7. home-search.png · 88×88 · 투명 · "구단주 검색"(상대 분석): 돋보기 + 방패, 민트 라인 아이콘.
8. home-squad.png · 88×88 · 투명 · "스쿼드 도우미": 전술판 위 선수 점 배치, 민트 라인 아이콘.
9. home-manager.png · 88×88 · 투명 · "감독모드": 작전판(클립보드) + 호루라기, 민트 라인 아이콘.
10~18. 메뉴 아이콘 48×48 · 투명 · 선 두께 3px 라인 아이콘, 색 #E8EAED 한 가지, 가장자리 4px 여백:
    nav-squad(전술판 위 점 배치), nav-picks(별+돋보기), nav-value(가격표+아래 화살표), nav-grade(계단 막대+위 화살표),
    nav-salary(저울), nav-trends(꺾은선 그래프), nav-mysquad(유니폼 셔츠), nav-opponent(과녁+방패), nav-teamcolor(겹친 원 3개).
19. empty.png · 160×100 · 투명 · "결과 없음" 안내: 축구공과 전술판 선의 미니멀 라인 일러스트, 회색 선 + 민트 포인트 하나.
20. player.png · 128×128 · 투명 · 선수 상세의 기본 사진 자리: 얼굴 없는 선수 실루엣(어깨 위), 원형 크롭, 회색 톤. 실제 사람처럼 보이면 안 됨.

[일관성]
- 모든 아이콘은 같은 선 두께·모서리·여백으로 한 세트처럼.
- 한 장씩 만들고, 만들 때마다 파일 이름과 크기를 다시 확인해 줘.
```

## 넣은 뒤 확인할 것
- 스쿼드 메이커의 선수 카드 글자가 카드 틀 위에서 잘 읽히는지(가운데가 밝으면 글자가 묻힌다).
- 창 배경 위의 표·글자 대비. 어두운 배경이 너무 밝으면 `background.png`를 빼면 원래대로 돌아간다.
- 폴더 전체 크기 2MB 이하.
