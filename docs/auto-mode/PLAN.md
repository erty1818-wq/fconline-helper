# 완전 자동 모드와 인게임 캡처 — 작업 계획

사용자 요청(2026-09-26):
- 늦게 켜서 매칭 화면을 놓쳤을 때 **인게임 화면**(점수판)에서도 캡처로 상대를 찾는다.
- **완전 자동**: 매칭되면 상대 정보 카드, 경기가 끝나면 경기 내용 카드가 저절로 뜬다.
- 상대 카드에는 구단가치, 급여 배분, 시세 배분, 선수 시즌 등을 넣는다. 작은 창에 다 넣지 말고 **설정에서 보고 싶은 정보를 켜고 끄며, 창 크기는 그에 맞게 자동으로** 바뀐다.

공통 규칙은 저장소 루트 `AGENTS.md`. 진행 기록은 `PROGRESS.md`.

## 확인한 사실 (2026-09-26, 사용자 인게임 스크린샷 1786×892, 제목줄 32px)

- 점수판(창 안쪽 기준 x 0.03~0.35, y 0.05~0.12): `내닉 0 5 상대닉 86:00`. 왼쪽이 홈. 오른쪽 위에 `공식경기 1vs1`.
- 아래 양쪽 패널에 조작 선수 이름, 그 아래 닉네임(왼쪽 = 점수판 왼쪽 사람).
- Windows OCR(앱의 `ScreenReader`)로 읽은 결과:
  - 전체 화면 그대로: 내 닉은 맞게, 상대 닉 "AUD콜대원"을 "AU唱대원"·"AUD를대원"으로 잘못 읽음.
  - 점수판만 잘라 **3배 확대**: "킹마카이", "AUD콜대원" 정확. 4배: 시각 "86:00"도 읽지만 닉을 "AUD*대원"으로 읽음. → 여러 배율로 읽어 후보를 모으고, API(id 조회)로 실제 닉을 고른다.
  - 점수 숫자(0, 5)는 어떤 자르기·배율로도 읽지 못했다(Windows OCR은 한 글자 숫자를 잘 못 읽는다). → 점수는 화면에서 얻지 않는다.
- 경기 기록 API 지연: 경기 직후 `SyncMyMatchesAsync`로 새 경기 0건. 공식 안내대로 1~2시간 뒤에 올라온다. → 경기 종료 카드는 공식 기록 없이 만든다.

## 작업

| ID | 작업 | 내용 |
|---|---|---|
| AM-01 | 인게임 캡처 | Ctrl+Alt+F를 인게임에서 눌러도 된다. 매칭 화면이 아니면 점수판을 잘라 3배·4배로 읽고, 아래 패널도 읽어 상대 후보를 만든다(`Core/InGameScreen.cs`). |
| AM-02 | 자동 감시 | 설정 "완전 자동". 게임 창이 **앞에 있을 때만** 2초마다 점수판 부분만 읽는다(작게 잘라 OCR). 점수판이 없을 때는 4초마다 전체를 읽어 매칭 화면을 찾는다. 상대를 찾으면 한 경기에 한 번만 조회한다. 게임이 뒤로 가거나 꺼지면 멈춘다. |
| AM-03 | 상대 카드 | 새 창 `MatchCard`. 항목: 기본(닉·등급·최근 전적·한 줄 요약, 항상), 구단가치, 급여 배분, 시세 배분, 선수 시즌, 약점, 위험 선수. 설정에서 켜고 끈다. SizeToContent로 크기 자동. 게임 옆에, 포커스를 뺏지 않고, 항상 위 아님. [자세히] → 구단주 검색 창. |
| AM-04 | 경기 종료 카드 | 점수판에서 85분 이후를 봤고 그 뒤 점수판이 사라지면 종료로 본다. 상대, 마지막으로 본 시각, 맞대결 전적, "공식 기록은 1~2시간 뒤 반영" 안내, [내 경기 동기화]. 결과 화면 캡처를 받으면 OCR로 점수·기록을 더한다(사용자에게 요청함). |
| AM-05 | 설정 | 완전 자동 선택 활성화, 카드 항목 켜기/끄기. |
